# ZapDPI — iOS приложение для обхода DPI-блокировок

**ZapDPI** — приложение для iPhone, которое позволяет обходить цензуру и блокировки сайтов и приложений, установленные регуляторами по технологии DPI (Deep Packet Inspection). Приложение использует локальное ядро **sing-box** и не требует разворачивания собственного VPS.

## ⚠️ Важное обновление: GitHub CI/CD приостановлен

Сборка `.ipa` через GitHub Actions приостановлена на неопределенный срок в связи с техническими ограничениями: Xcode и нативная компиляция iOS-приложений доступны только на macOS. В текущих условиях (Windows/Linux) impossible собрать настоящий `.ipa` файл без доступа к macOS с Xcode.

**Решение:** Использовать `xtool` для генерации Xcode-проекта, который затем открывается на Mac для подписи и архивации.

## 🎨 Дизайн

Интерфейс построен на **SwiftUI** в стиле **Liquid Glass** — плавающий стеклянный таб-бар в стиле iOS 18, полупрозрачные карточки, градиентные кнопки и мягкие тени.

## 📱 Навигация (3 вкладки)

| Вкладка | Описание |
|---------|----------|
| **Главная** | Кнопка включения/выключения VPN, монитор входящего и исходящего трафика в реальном времени, информация о режиме работы (системный VPN / внутрипроцессный) |
| **Config** | Редактор JSON-конфигурации ядра sing-box/Xray-core с моноширинным шрифтом, настройки обхода DPI (фрагментация, TLS Client Hello, SNI, задержки пакетов), кнопка «Сохранить и применить» |
| **Настройки** | Маршрутизация (прямая / туннель), IPv6, выбор DNS (Cloudflare / Google / Quad9 / свой), уровень логов, диагностика, управление сохранёнными конфигурациями |

## ⚠️ Важные технические ограничения iOS

Из-за закрытости iOS и правил безопасности Apple:

1. **Бесплатная подпись (SideStore / AltStore / Sideloadly / 7 дней)** — системный фреймворк `NetworkExtension` (`NEPacketTunnelProvider`) **недоступен**. Приложение автоматически переходит в **внутрипроцессный режим (In-App Tun/Proxy)** без создания полноценного системного VPN-расширения.
2. **LiveContainer** — нет JIT-компиляции по умолчанию (может потребоваться активация через AltStore/SideStore). Жёсткие лимиты ОЗУ (обычно 15–50 МБ) — конфигурация не должна содержать миллионных списков заблокированных IP.
3. **Локальный обход DPI** работает только внутри TCP/UDP-сессий, которые приложение может перехватить на уровне локального туннеля (L3/L7). Не все сырые пакеты ядра iOS можно модифицировать.

## 🛠️ Сборка через xtool (решение без прямой нужды в macOS для первого шага)

Инструмент `xtool` (https://github.com/xtool-org/xtool) позволяет генерировать структуру Xcode-проекта на платформах Windows/Linux, после чего проект можно открыть в Xcode на Mac для финальной сборки `.ipa`.

### Как использовать xtool с проектом ZapDPI:

**1. Установка xtool:**

```bash
# Клонируем репозиторий xtool
git clone https://github.com/xtool-org/xtool.git

# Переходим в директорию
cd xtool

# Устанавливаем зависимости
pip install -r requirements.txt
```

**2. Подготовка проекта ZapDPI:**

```bash
# Клонируем или копируем наш проект
git clone https://github.com/your-username/ZapDPI.git
cd ZapDPI
```

**3. Генерация Xcode-project:**

```bash
xtool generate \
  --config xtool_config.json \
  --output ./build
```

Это создаст папку `./build/` с файлом `ZapDPI.xcodeproj` (или структурой, аналогичной Xcode-project), которую можно открыть в Xcode на системе macOS.

**4. Дальнейшая сборка .ipa:**

После генерации проекта xtool'ом:

1. Откройте `./build/ZapDPI.xcodeproj` в Xcode на macOS
2. Настройте подпись (Signing & Capabilities) под ваш Apple ID
3. Выполните `Product → Archive`
4. Экспортируйте `.ipa` через интерфейс Xcode (метод: Ad Hoc / Development / App Store)

**5. Установка полученного .ipa на iPhone:**

- Через SideStore / AltStore (бесплатная подпись, 7 дней)
- Через LiveContainer
- Через iLoader с ПК

### Важные заметки about xtool:

- **xtool генерирует структуру проекта**, но **финальная подпись и архивация .ipa всё равно требуют Xcode на macOS** из-за ограничений Apple по NetworkExtension и кодовому signingu.
- Для **бесплатной подписи Apple** режим работы уже настроен в `VPNManager.swift` (fallback на In-App Tun/Proxy).
- Инструмент упрощает создание проекта, но не обходит систему требований Apple для распределения приложений.
- Если нужна сборка полностью на Windows/Linux — невозможно из-за лицензионных и технических ограничений Apple.

## ⚠️ GitHub CI/CD приостановлен

Сборка через GitHub Actions приостановлена до тех пор, пока не будет обеспечен доступ к环境у с macOS и Xcode. Причины:
- Xcode не запускается на Windows/Linux
- NetworkExtension (системный VPN) недоступен при бесплатной подписи
- Ограничения Apple по распределению собранных файлов

Работа продолжается путем использованияxtool для генерации проекта, после чего сборка происходит на Mac или арендованном сервере.

## 🔐 Подпись и провижининг

- Для **бесплатной аккаунта Apple** (Apple ID) доступна только локальная подпись на 7 дней.
- Для полноценного `NetworkExtension` (системный VPN) требуется **Apple Developer Program** ($99/год) и соответствующий профиль провижининга.
- В файле `ZapDPI.entitlements` ключи `com.apple.developer.networking.networkextension` закомментированы — раскомментируйте их при наличии платной подписки.
